# PondoLens

A data engineering project exploring Philippine government spending across sectors, agencies, and regions, alongside population and economic indicators.

## Project Status

Development is ongoing. The `main` branch is reserved for reviewed and approved releases.

## Branches

- `main` — approved releases
- `dev` — integration and testing
- `feat/*` — ingestion, profiling, and other development work

Submit feature pull requests to `dev`. Merge to `main` once changes have been reviewed and validated.

## Current Scope

- Budget data: 2024–2025
- Population projections: 2020–2035
- GRDP and GRDP per capita: 2023–2025

Budget data for 2021–2023 is planned for a later phase.

## Tools

Databricks, PySpark, SQL, Delta Lake, Python, and GitHub Actions.
